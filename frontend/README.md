# EV Location Planner frontend
Run npm ci then npm run dev. Backend must run on port 8000. Vite proxies /api locally. For production set VITE_API_BASE_URL to the HTTPS backend origin and allow the frontend origin in FastAPI CORS. Build with npm run build. Vercel SPA rewrites included. Map tiles use OpenStreetMap standard tiles, suitable for low-volume demo only, subject to tile usage policy. No frontend secrets required. Login uses sessionStorage bearer token. Account schema only supports email/password. Dashboard uses current session data, not fabricated statistics. Preferences are stored but not applied to scoring. Admin records are separate from external station data. No automatic candidate generation. Test against live backend before deployment. Reference artwork cropped from supplied design.
